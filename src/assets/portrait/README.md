# Portrait masks

Generated by `scripts/portrait.mjs` from David's photo (5 November 2026). Do not edit by hand.

- `portrait-ink.webp`: the duotone ink layer. Only its alpha is used (as a CSS mask): opaque where the photo is dark, transparent where it is light. 640 × 640, 16 tone steps.
- `portrait-pink.svg`: the pink halftone copy on the 9 px grid of the 400 px design, also used as a mask.

The colours come from the tokens in `About.astro`. The original photo is not committed: it carries camera metadata (LEG-007). To rebuild, for example after a new photo or a different crop:

```bash
node scripts/portrait.mjs path/to/photo.jpg --x 0.052 --y 0.2246 --size 0.8333
```

`--x`, `--y` and `--size` place the square crop as fractions of the photo's width. Then re-run the flash check (`docs/audits/2026-11-05/flash-analysis.md`).
