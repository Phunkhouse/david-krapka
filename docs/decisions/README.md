# Decision records

Write one short record when a reasonable future maintainer might ask **why** a significant choice was made. Routine implementation details do not need one.

Copy `template.md` to `0001-short-title.md` and increment numbers without renumbering older records. Record only alternatives that were actually considered. If a decision changes, write a new record and mark the old one as superseded.
