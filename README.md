# David Křapka — osobní portfolio

Příprava osobního portfolia s positioningem **Product-minded Engineer**. Cílem je představit produktové přemýšlení, engineering a osobní značku zaměstnavatelům i potenciálním klientům.

Repozitář je ve fázi briefu a obsahové přípravy. Web zatím není implementovaný.
